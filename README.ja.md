# Dayspan

[English](README.md) | [日本語](README.ja.md)

自分で選んだ一日と、今日との「あいだ」を見えるようにするObsidianプラグインです。

Dayspanは、Markdownノートから自分で選んだ出来事を記録し、「あれからどれくらい経ったか」「その日まであとどれくらいか」を一覧にします。Vault全体を自動解析せず、何を残すかは自分で選べます。

> [!NOTE]
> Dayspanは現在、GitHubとBRATを通じて公開ベータ版を配布しています。まだObsidianのコミュニティプラグイン一覧から直接インストールすることはできません。

## 主な機能

- Markdownの編集モード・閲覧モードで選択した文章を登録
- 節目や未来の日付を手動登録
- 「あと何日」「今日」「あれから何日」へ自動分類
- 記録ごとに次の表示形式を選択
  - 日数
  - 月数
  - 年数
  - 月＋日
  - 年＋月＋日
- 3つのセクションを並べ替え
- セクションごとに折りたたみ・展開し、その状態を保存
- 未来と過去の表示色を変更
- 保存した記録内に、登録元ノートへのクリック可能なリンクを残す
- 1件ずつ読みやすいMarkdownファイルとして保存
- デスクトップとモバイルの両方に対応

月数と年数は、30日・365日の固定換算ではなく、実際のカレンダー上で完了した月・年を数えます。

## 使い方

1. Markdownノートで残したい文章を選択します。
2. コマンドパレットから「選択した文章を登録」を実行します。編集モードでは右クリックの「Dayspanに登録」も使えます。
3. 名前、基準日、表示形式を確認して登録します。
4. リボンのカレンダーアイコン、またはコマンドパレットの「一覧を開く」から確認します。

文章を選択せずに、誕生日、年齢の節目、記念日、期限などを「手動で登録」することもできます。

## データとプライバシー

Dayspanはローカルかつオフラインで動作します。

- 外部サービスへ接続しません。
- 利用状況や解析データを収集しません。
- 広告を表示しません。
- 選択元のノートを変更しません。
- 登録内容をVault内のMarkdownファイルとして保存します。
- 設定をObsidian標準のプラグイン設定ファイルへ保存します。

新規インストール時の保存先は`Dayspan`です。設定画面から変更できます。すでに保存先を設定している場合は、その設定が維持されます。

## インストール

### BRAT（ベータ期間中の推奨方法）

1. Obsidianのコミュニティプラグイン一覧から**BRAT**をインストールして有効化します。
2. **設定 → BRAT**を開き、**Add beta plugin**を選択します。
3. リポジトリとして`shingotanaka0115/dayspan`を入力します。
4. **設定 → コミュニティプラグイン**から**Dayspan**を有効化します。

BRATはGitHub Releaseを確認し、今後のベータ版へ更新できます。Dayspanのバージョンは`0.1.2`のように、先頭に`v`を付けない形式です。

### 手動インストール

1. GitHub Releaseから`main.js`、`manifest.json`、`styles.css`をダウンロードします。
2. `<Vault>/.obsidian/plugins/dayspan/`フォルダを作成します。
3. 3つのファイルをフォルダへコピーします。
4. Obsidianを再読み込みし、「設定 → コミュニティプラグイン」からDayspanを有効にします。

公式審査後は、コミュニティプラグイン一覧から直接インストールできるようになります。

## 開発

Node.js 20以上とnpmが必要です。

```bash
npm install
npm run dev
```

コミットまたはリリース前に、次を実行します。

```bash
npm run check
```

リリースに添付するファイルは`main.js`、`manifest.json`、`styles.css`です。ローカル設定の`data.json`と生成物の`main.js`は、ソース管理から除外します。
